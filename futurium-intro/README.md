# Futurium · Інструмент ведення інтро-консультації

Прототип. Веб-застосунок для проведення діагностичної консультації
з генерацією персонального PDF-плану навчання.

## Запуск

```bash
npm install
npm run dev            # http://localhost:5173
npm run build          # збірка для Vercel → dist/
npm run build:single   # один самодостатній .html → dist-single/
```

## Що де лежить

```
src/config/     ← ВЕСЬ методичний контент. Правиться без дотику до коду.
src/lib/        розрахунки, рекомендації, збереження
src/screens/    екрани 0–9
src/components/ спільні елементи (шкала рівнів, таймлайн, редаговані поля)
src/pdf/        макет PDF — окремий від екранів
src/index.css   ← ЄДИНЕ місце, де живуть кольори (CSS-змінні)
```

### Файли, які заповнює школа

Кожен має коментар `// ЗАПОВНЮЄ ШКОЛА` зверху.

| Файл | Що в ньому |
|---|---|
| `levels.ts` | що вміє / над чим працюємо на кожному рівні |
| `durations.ts` | скільки уроків займає перехід між рівнями |
| `checkpoints.ts` | що перевіряємо на кожному зрізі |
| `formats.ts` | формати, **ціни**, правила рекомендації |
| `benefits.ts` | що входить у вартість (порядок важливий) |
| `goals.ts` | цілі й розшифровка в навички |
| `lesson-structure.ts` | етапи уроку, слот під скріншот |
| `next-steps.ts` | тексти карток і дедлайни |
| `school.ts` | контакти, посилання на запис |
| `prompts.ts` | опори для розмови на екрані 1 |
| `theme.ts` | дзеркало кольорів для PDF |

## Два режими

- **Приватний** (екрани 0–1): бачить лише ведуча. Введення кліками, повна навігація.
- **Презентаційний** (екрани 2–9): бачить клієнт. Великий шрифт, навігація
  майже невидима, усі тексти редаговані по кліку прямо під час показу.

Між ними — екран переходу з нагадуванням увімкнути демонстрацію екрана.

Гортання: `←` / `→`. Вихід із презентації: `Esc`.

## Дані

Бекенду немає. Поточна сесія автозберігається в `localStorage` при кожній зміні.
Список сесій — на стартовому екрані, є експорт усіх сесій у JSON.

Поля в `ConsultationSession` названі так, щоб мапитись на поля CRM без
перейменувань, коли з'явиться бекенд.

## Перевірено

Наскрізний прогін усіх екранів у Chromium на 1440×900:

- екран 1 вміщається без скролу (`scrollHeight` = `clientHeight` = 900)
- помилок у консолі немає
- PDF: 3 сторінки, 121 КБ (ліміт 2 МБ), кирилиця коректна,
  посилання на запис клікабельне й несе UTM-мітку
