# Куди залити, щоб поділитись із командою

Бекенду немає, це статика: HTML + JS + шрифти. PDF збирається **в браузері
користувача**, нічого не надсилається на сервер. Тому підходить будь-який
статичний хостинг, і жоден не потребує бази, серверів чи env-змінних.

---

## Варіант 1 · Vercel — основний

Те, що вказано в ТЗ. Постійне посилання, автоматичне оновлення при кожному
пуші в гілку.

**Що потрібно:** акаунт Vercel (безкоштовний Hobby), доступ до GitHub-репозиторію.

1. vercel.com → **Add New** → **Project** → **Import Git Repository**
2. Обрати репозиторій зі застосунком
3. У налаштуваннях імпорту:
   - **Framework Preset:** Vite *(підтягнеться сам)*
   - **Root Directory:** `futurium-intro` ← **обов'язково**, якщо застосунок
     лежить у підпапці репозиторію
   - Build Command і Output Directory чіпати не треба — вони в `vercel.json`
4. **Deploy**

Через ~40 секунд буде посилання виду `https://<назва>.vercel.app`.
Команді достатньо його відкрити — нічого встановлювати не треба.

**Своє доменне ім'я:** Project → Settings → Domains. Можна причепити
піддомен основного сайту, напр. `consult.futurium.school`.

**Обмеження безкоштовного плану, які тут важать:** посилання публічне.
Закрити його паролем на Hobby не можна — це платна функція
(Deployment Protection). Якщо треба закрити — див. «Про приватність» нижче.

## Варіант 2 · Netlify Drop — найшвидший, без Git

Коли треба показати команді **прямо зараз**, без налаштування репозиторію.

1. Зібрати: `npm run build` → з'явиться папка `dist/`
2. Відкрити **app.netlify.com/drop**
3. Перетягнути папку `dist` у вікно браузера

Готово, посилання з'явиться одразу. Акаунт можна не створювати, але без
нього посилання тимчасове — краще залогінитись, щоб закріпити.

Мінус: оновлення = перетягнути папку заново. Для довгої роботи краще Варіант 1.

---

## Варіант 3 · Один HTML-файл — офлайн, без хостингу взагалі

`npm run build:single` збирає **весь застосунок в один файл** `dist-single/index.html`
(~2 МБ): шрифти й логотип зашиті всередину як data-URI, жодних зовнішніх
запитів. Перевірено: відкривається подвійним кліком із диска, всі екрани
працюють, PDF генерується.

Цей файл можна просто надіслати в Telegram чи поштою. Кожен відкриває його
у своєму браузері.

Мінуси: 2 МБ на кожну пересилку, і при кожній правці треба розсилати наново.
Добре як запасний варіант і для показу без інтернету.

## Про приватність

Посилання на безкоштовному плані **публічне**: хто його має, той відкриє.
Пошуковики його не знайдуть (індексації немає, посилань нізвідки не веде),
але це «неочевидне», а не «закрите».

Якщо цього замало:

- **Cloudflare Access** перед доменом — безкоштовно до 50 користувачів,
  вхід за списком email. Найпростіший спосіб зробити по-справжньому закрито.
- **Vercel Pro** — вбудований захист паролем.
- Простий пароль у самому застосунку — приховає від випадкового ока,
  але не захистить: код сторінки видно кожному, хто відкриє посилання.

## Що важливо знати команді

**Сесії зберігаються локально в браузері.** У кожного, хто відкриє
посилання, свій набір збережених консультацій. Вони не синхронізуються між
людьми й між пристроями. Для v1 це за задумом — інструмент веде одна людина.

Звідси випливає: якщо засновниця веде консультації з ноутбука, а потім
відкриє посилання з телефона — там буде порожньо. Історія прив'язана до
конкретного браузера. Кнопка «Експортувати всі сесії у JSON» на стартовому
екрані існує саме для перенесення.

**Очищення даних браузера стирає історію сесій.** Поточний PDF це не
зачіпає — він уже завантажений, — але список консультацій зникне.
